# Phase 26 Plan 01: Canonicalize Epic Directions

## Objective

Restore the missing v1.3 direction specification as a single canonical document so
Phases 27-31 have a stable shared reference. The document must match the actual
structural choices already implemented for Designs A and B and the documented
foundation direction now in progress for Design C.

## Inputs

- `.planning/v1.3-MILESTONE-BRIEF.md`
- `.planning/phases/27-epic-skin-a/27-RESEARCH.md`
- `.planning/phases/27-epic-skin-a/27-VERIFICATION.md`
- `.planning/phases/28-epic-skin-b/28-RESEARCH.md`
- `.planning/phases/28-epic-skin-b/28-VERIFICATION.md`
- `.planning/phases/29-epic-skin-c/29-RESEARCH.md`
- `.planning/phases/29-epic-skin-c/29-01-PLAN.md`

## Required Output

Create `.planning/phases/26-epic-directions/26-EPIC-DIRECTIONS.md` with:

1. Shared constraints that carry across all three skins.
2. One section per direction with an explicit `Structural Signature`:
   - homepage section ordering
   - hero composition type
   - navigation pattern
   - visual signature element
   - copy strategy
3. A differentiation matrix proving at least three structural differences between
   each pair of designs.
4. Enough specificity that later planning and review work can reference the file
   instead of reverse-engineering the skins from code.

## Verification

Write `26-VERIFICATION.md` confirming:

- three directions exist
- hero composition types are unique
- homepage ordering differs across A/B/C
- each design has one clearly named visual signature
- each design has a distinct copy emphasis
- the matrix documents at least three pairwise structural differences

## Success Condition

Phase 26 is considered restored when the directions document can serve as the
single shared source of truth for later implementation, polish, and review work.
