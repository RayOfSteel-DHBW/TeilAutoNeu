<interfaces>
Direction C design tokens (from 23-01):
- Primary: #b5541a (terracotta)
- Accent: #d4853a (amber-ochre hover)
- Surface: #fdf6ee (warm cream)
- Ink: #33261a (dark warm brown)
- Muted: #f0e6d6 (sand)
- Display font: Nunito
- Body font: DM Sans

Direction C layout rules:
- USES CARDS: rounded-2xl bg-brand-muted p-8 shadow-md shadow-brand-primary/8
- No visible borders on cards -- separation through bg color difference + shadow
- py-14 between sections
- Content width: max-w-5xl (64rem)
- CTA buttons: rounded-full, bg-brand-primary, hover:bg-brand-accent

Direction C table styling:
- Table container: rounded-xl border border-brand-primary/15 overflow-hidden
- Header row: bg-brand-muted (sand background)
- Table headings: text-left text-sm font-semibold text-brand-ink, px-4 py-3
- Data cells: text-sm text-brand-ink/80, px-4 py-3
- Row dividers: divide-y divide-brand-primary/10
- This is a DIFFERENT table treatment from Direction B (which uses divide-y on bare tables, no container border)
</interfaces>
