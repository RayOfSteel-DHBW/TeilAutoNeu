Tera template structure:
- base.html: extends nothing, defines blocks (title, head, header, main, footer)
- page templates: {% extends "base.html" %} and override blocks
- partials: header.html, footer.html (included by base.html)

Build system: PowerShell script processes all .html in site/src/ through Tera, then runs Tailwind CLI.

CRITICAL DIFFERENCES FROM DIRECTIONS A AND B:
- Direction C uses a TWO-FONT system: Nunito (display) + DM Sans (body), NOT a single font
- Direction C SHOWS phone number in nav as a small terracotta pill button
- Direction C buttons are rounded-full (pill shape), NOT rounded-md or rounded-lg
- Direction C has warm cream surface (#fdf6ee) -- noticeably warmer than B's #fafafa
- Direction C footer is bg-brand-primary (terracotta), white text
- Direction C active nav indicator is bg-brand-muted pill behind text (NOT underline, NOT dot)
- Direction C mobile overlay has pill-shaped links and warm organic decorative blob
- Direction C uses a fixed bottom phone BAR (full width) on mobile, NOT a floating circle button
- Direction C content width is max-w-5xl (same as B, different from A)
