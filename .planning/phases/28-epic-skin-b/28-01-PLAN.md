Also add the diagonal-rule utility class and any custom components (diagonal accent line CSS) after the @theme block.

**base.css** -- Adapted from research code examples section. Must include:
- `@layer base` with box-sizing, body defaults, heading clamps (h1/h2/h3 with `clamp()`), focus-visible outline using `#a3e635`
- `.fleet-map` container class (420/480/520px responsive heights)
- `.fleet-marker` and `.fleet-popup` classes for MapLibre
- `scroll-behavior: smooth` with `prefers-reduced-motion` media query

**js/nav.js** -- Custom floating pill nav toggle. NOT a copy of site/public/js/nav.js (which targets `#primary-nav`). Write new nav.js that:
- Targets `#mobile-nav` overlay and the hamburger button `[aria-controls="mobile-nav"]`
- Toggle: click hamburger -> add `flex`, remove `hidden` on `#mobile-nav`, set `aria-expanded="true"`
- Close: click close button (inside overlay), or press Escape key
- Body scroll lock: `document.body.style.overflow = 'hidden'` on open, `''` on close
- Active page indicator: detect current page from `window.location.pathname` and set `aria-current="page"` on matching `#floating-nav` links

**js/pricing.js** -- Copy of `site/public/js/pricing.js` with ONE change: `var PRICING_URL = "../../public/data/pricing.json";` (line 12). Everything else unchanged.

**js/accordion.js** -- Direct copy of `site/public/js/accordion.js` (unchanged, used for FAQ on ueber-uns page).

**HTML structure (top to bottom):**

1. `<head>`: charset, viewport, title "teilAuto Moessingen -- Carsharing", Google Fonts CDN link (Plus Jakarta Sans 500-800 + Inter 400-600), link to `tailwind-out.css`, link to `base.css`, OG meta tags (og:type=website, og:locale=de_DE)

2. **Skip-to-content link**: `<a class="sr-only focus:not-sr-only" href="#main-content">Zum Inhalt springen</a>`

3. **Floating pill navigation** (per research Pattern 2): `<nav>` with `fixed top-4 left-1/2 z-50 -translate-x-1/2`, containing rounded-full pill with logo "teilAuto", desktop links (Preise, Fahrzeuge, Fuer Firmen, Ueber uns), "Mitglied werden" CTA pill, mobile hamburger button. Use `bg-brand-surface/95 backdrop-blur-md shadow-xl border border-brand-ink/10`.

4. **Mobile nav overlay** (`#mobile-nav`): Full-screen dark overlay with centered large links, close button, phone number, diagonal accent decoration in corner.

5. **Section 1: Asymmetric split hero** (per research Pattern 1): `min-h-[calc(90vh-0px)]`, `bg-brand-primary` (dark). Left 60% (`lg:w-3/5`): eyebrow tag "Carsharing in Moessingen", h1 "Kein eigenes Auto -- trotzdem mobil." with "trotzdem mobil" in `text-brand-accent`, supporting paragraph about only paying when driving, two CTA buttons (lime "Mitglied werden" + ghost "Preise ansehen"). Right 40% (`lg:w-2/5`, `hidden lg:flex`): typographic stat block showing ~60 Mitglieder / 2 Fahrzeuge with diagonal accent corner decoration. Inner content div needs `pt-20` to clear floating nav. Diagonal accent line in hero background.

6. **Section 2: Savings comparison** (per research Pattern 5 -- "Was kostet ein Zweitwagen wirklich?"): Two-column grid comparing Eigenes Zweitauto costs (Versicherung ~600 EUR/Jahr, Kfz-Steuer ~100, Wartung/TUEV ~300, Stellplatz) vs. teilAuto Mitglied benefits (Jahresbeitrag loaded via JS `#pricing-join-fee`, Versicherung inklusive, Kraftstoff inklusive, Nur zahlen wenn Sie fahren). Disclaimer "Alle Vergleichswerte zur Orientierung." Left card plain, right card accent-bordered with highlight background.

7. **Section 3: Membership gate** -- "Mitglied werden: So einfach wie eine Bibliothek". Explain membership model clearly: not a rental service, join as member, then book vehicles. Use `bg-brand-muted`. Include diagonal accent divider.

8. **Section 4: How it works** -- 3-step horizontal layout: "Anmelden", "Buchen", "Losfahren". Each step has a number in large `font-display text-5xl text-brand-accent`, a title, and brief description. On `bg-brand-surface`.

9. **Section 5: Fleet preview** -- Dark section (`bg-brand-primary`). Show 2 Fahrzeuge in Moessingen + Quernutzung network mention. Link to fahrzeuge.html. Include diagonal accent lines.

10. **Section 6: Final CTA** -- Bright section using `bg-brand-accent`. Dark text (`text-brand-primary`). Large heading inviting to call. Phone number `07473-922202` as prominent link. "Mitglied werden" button.

11. **Footer** (per research footer pattern): Dark green, 3-column grid (brand info, page links, contact with phone). Diagonal accent line above copyright. Copyright line with Impressum/Datenschutz links.

12. **Mobile bottom phone bar**: Fixed bottom, lime CTA "Jetzt anrufen: 07473-922202", hidden on lg+.

13. **Scripts**: `<script src="js/nav.js" defer></script>`

**Copy strategy**: Cost-forward emotional arc. Lead with savings and practical value. Use "Sie" throughout. German language, sachlich+freundlich. No invented facts -- use verified content from v1.2 pages (reworded for cost-first emphasis).
