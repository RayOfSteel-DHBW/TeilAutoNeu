  <action>
Fix all BLOCKING and VISUAL issues found in Task 1. Common fixes expected based on research pitfalls:

**Likely issues and fixes:**

1. **Floating nav overlapping hero content**: Add or increase `pt-20` on hero inner content divs. Verify the floating nav at `top-4` (16px from top) doesn't clip the first content element.

2. **Horizontal overflow on mobile**: Add `overflow-x: hidden` to `<body>` or `<html>` in base.css if diagonal accent lines cause overflow. Apply `break-words` / `overflow-wrap: break-word` to long German text containers.

3. **Electric lime on white contrast**: If any CTA buttons have white text on lime background, change to `text-brand-primary` (dark green).

4. **Asymmetric split at wrong breakpoint**: Ensure the split is `lg:` (1024px+), NOT `md:`. At 768px the hero should be stacked.

5. **Mobile nav overlay scroll**: If background scrolls when mobile nav is open, verify nav.js adds `document.body.style.overflow = 'hidden'`.

6. **Legal page text overflow**: German compound words may break layout at 375px. Add `hyphens: auto` and `overflow-wrap: break-word` to legal content containers.

7. **Map container height**: If the fleet-map container doesn't render at correct height, verify `class="fleet-map"` is present and base.css `.fleet-map` styles are loaded.

8. **Inconsistent nav across pages**: Ensure all 8 pages have identical floating nav markup (except for aria-current attributes).

**Fix process:**
1. Address all BLOCKING issues first
2. Address VISUAL issues
3. Recompile Tailwind after fixes: `cd site && npx @tailwindcss/cli -i epic/b/style.css -o epic/b/tailwind-out.css`
4. Re-screenshot fixed pages to verify
5. Iterate until no BLOCKING or VISUAL issues remain
