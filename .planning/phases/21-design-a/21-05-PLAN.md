  <action>
This task uses the Playwright MCP (browser tools) to take screenshots, evaluate visual quality, and fix issues. This is an iterative process.

**Prerequisites:**
1. Ensure site is built: `cd site && npm run build`
2. Ensure live server is running at http://127.0.0.1:5500/site/build/dist/ (the user should start this if not running — ask if needed)

**Audit process (repeat for each page):**

For each of the 8 pages:
1. Navigate to the page at each breakpoint using Playwright browser tools
2. Take a screenshot at each breakpoint (375px, 768px, 1280px)
3. Evaluate the screenshot for issues:
   - **Layout breaks:** Elements overflowing viewport, horizontal scroll, misaligned grids
   - **Typography issues:** Text too small on mobile, headings not scaling properly, wrong font visible
   - **Color issues:** Incorrect colors, poor contrast, v1.1 green still appearing
   - **Spacing issues:** Too much/little padding, elements touching edges, inconsistent margins
   - **Navigation:** Mobile nav overlay working, hamburger visible, phone number accessible
   - **Interactive elements:** Map rendering on fahrzeuge, pricing data on preise
   - **CTA visibility:** Phone number visible, CTA buttons properly styled

4. If issues found, fix the source files, rebuild, and re-screenshot to verify

**Breakpoint workflow:**
```
For width in [375, 768, 1280]:
  1. Resize browser to width x 900
  2. For page in [index, preise, fahrzeuge, geschaeftskunden, ueber-uns, mitglied-werden, impressum, datenschutz]:
    a. Navigate to http://127.0.0.1:5500/site/build/dist/{page}.html
    b. Take full-page screenshot
    c. Evaluate for issues
    d. If issues: fix source, rebuild, re-screenshot
```

**Issue priorities (fix all):**
- P0: Page doesn't render, white screen, build error
- P1: Horizontal overflow, elements off-screen, unreadable text
- P2: Misaligned grid, wrong spacing, color inconsistency
- P3: Minor spacing tweaks, subtle alignment improvements

**After fixing all issues:**
- Rebuild: `cd site && npm run build`
- Take final screenshots at all 3 breakpoints for all 8 pages as evidence
- Commit all fixes

**IMPORTANT:** This task REQUIRES IMPL-06 (Frontend Design Plugin). Use the Playwright browser tools (browser_navigate, browser_resize, browser_take_screenshot, browser_snapshot) for visual auditing. If the site is not running on localhost, ask the user to start it.
