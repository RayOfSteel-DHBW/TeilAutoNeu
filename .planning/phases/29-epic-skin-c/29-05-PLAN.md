7. **Mobile bottom bar** — present on mobile, hidden on desktop, content has bottom padding
8. **Font loading** — DM Serif Display and Figtree rendering (not falling back to system fonts)
9. **Tailwind CDN** — styles applying correctly (not seeing unstyled HTML)

**Fix process:**
For each issue found:
1. Identify the file and element
2. Apply the fix (adjust Tailwind classes, add responsive breakpoint classes, fix padding/margins)
3. Re-screenshot to verify the fix

- "Datenschutzerklaerung" h1 overflow at 375px → needs text-3xl sm:text-4xl not text-5xl

- Nav links crowding at 768px → must use `lg:` not `md:` for desktop display
