Create `.planning/phases/20-research/20-DESIGN-DIRECTIONS.md` with this structure:

**Preamble:**
- Brief statement of purpose: this document is the design spec for Phases 21-23
- v1.1 visual identity summary (from INSPIRATION-NOTES Section 4) as contrast baseline

**Shared Constraints section:**
Copy the 15 constraints from INSPIRATION-NOTES Section 5. Every direction must satisfy all of these. Include:
- Tailwind v4 `@theme` syntax for color tokens
- Google Fonts CDN with German character support
- 8 fixed pages
- Phone CTA only (07473-922202)
- Membership gate messaging
- No invented content
- Zweitwagen persona (Simone) primary
- Responsive: 375px, 768px, 1280px+
- CSS/SVG/gradient backgrounds only (no photos)
- pricing.json/pricing.js pattern preserved
- MapLibre map on fahrzeuge.html

**Direction A, Direction B, Direction C** — each direction MUST include all 8 items from the rationale framework (20-RESEARCH.md, "Design Direction Rationale Framework"):

1. **One-sentence creative brief** — the direction's personality in one sentence
2. **Google Fonts pair** — exact font names, weights to load, which is body vs. display. MUST support German umlauts. Verify by confirming the fonts exist on fonts.google.com and support Latin Extended or similar charset.
3. **Color palette** — exactly 5-6 hex values with semantic names:
   - `primary` — main brand color
   - `accent` — secondary color for highlights/CTAs
   - `surface` — page background
   - `text` (or `ink`) — primary text color
   - `muted` — hover states, subtle backgrounds
   - Optional: `cta` if different from accent
   Include the exact `@theme` block that would go in tailwind.css.
4. **Hero concept** — what the homepage hero looks like at 1280px desktop:
   - Background approach (CSS gradient, SVG pattern, solid color, or abstract CSS shapes)
   - Headline tone and approximate wording direction (grounded in existing content from INSPIRATION-NOTES)
   - CTA button placement and style
   - Height approach (full viewport, 70vh, etc.)
5. **Card/section style** — how content sections are presented:
   - Border style, corner radius (Tailwind class), shadow
   - Background color
   - Spacing convention
   - Whether this direction uses cards, or replaces cards with a different pattern (sections with dividers, editorial blocks, etc.)
6. **Nav treatment** — desktop and mobile:
   - Sticky vs. static
   - Background/transparency
   - Mobile hamburger approach
   - Active page indicator style
7. **Conversion hooks** — how the Simone/Zweitwagen persona is addressed:
   - Where the membership gate message appears
   - How the phone number (07473-922202) is displayed
   - Call-to-action copy tone (e.g., "direct and practical" vs. "warm and inviting")
   - Key pages in the conversion funnel
8. **What makes this unmistakably different** — the differentiation statement:
   - How this differs from v1.1 (at least 3 specific contrasts)
   - How this differs from the other two directions (at least 2 specific contrasts each)

**Differentiation Matrix** — a comparison table with 4 rows (v1.1, Direction A, Direction B, Direction C) and columns for: Color Family, Typography Style, Layout Approach, Card Style, Hero Type, Personality. No two rows should share more than 1 column value.

Start from the three archetype hypotheses in 20-RESEARCH.md but refine, rename, and make fully concrete:
- Archetype A "Newspaper Clarity" -- high typographic contrast, editorial grid, serif headings, muted warm neutral palette
- Archetype B "Nordic Utility" -- ultra-minimal, large whitespace, geometric sans, single bold accent, near-white palette
- Archetype C "Warm Local" -- earthy tones, friendly rounded typography, warm gradient hero, community emphasis

These are starting points. Refine each based on what the inspiration catalogue actually contains. Rename if a better name emerges. The final names should be evocative and distinct.

CRITICAL CONSTRAINTS on the rationale writing:
- All example copy must come from INSPIRATION-NOTES content opportunities or existing v1.1 text. Never invent business claims.
- All Google Fonts must be verified as supporting German characters (aeoeueess). Safe choices from RESEARCH.md: Inter, Plus Jakarta Sans, Outfit, Sora, DM Sans, Nunito, Figtree (body); Raleway, Josefin Sans (headings); Playfair Display (serif heading).
- No direction may use green as its primary color (v1.1 already occupies that space).
- No direction may use `rounded-3xl` white cards on a pale surface as its primary section style (that IS v1.1).
- Each color palette must be a complete `@theme` block ready to paste into tailwind.css.
