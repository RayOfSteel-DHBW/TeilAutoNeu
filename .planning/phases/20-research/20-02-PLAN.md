Read the completed `.planning/phases/20-research/20-INSPIRATION-NOTES.md` from Plan 01. Also re-read `.planning/PROJECT.md` for constraints, personas, and key decisions.

Synthesize three DISTINCT design directions. Each direction must:

1. **Differ from v1.1** — v1.1 uses white/green Tailwind palette, standard card layouts, conventional hero structure. Each new direction must feel visually different.
2. **Differ from each other** — a user viewing all three side-by-side should immediately recognize three different visual identities.
3. **Serve the Zweitwagen persona** — Simone is the primary persona. Each direction's hero, copy tone, and flow must be conversion-optimized for "I need a practical second car alternative."
4. **Be production-ready achievable** — no exotic animations, no custom illustration requirements, no dependencies beyond HTML + Tailwind CSS. Each must be implementable by Claude in a single design phase.

For each direction, document:

**Visual Concept** (the "feeling"):
- One-sentence creative brief (e.g., "Clean Swiss minimalism that lets content breathe")
- Mood/aesthetic description — what does it feel like to browse this site?
- How does it differ from v1.1 and the other two directions?
- Key visual differentiator (the one thing that makes this direction instantly recognizable)

**Type + Color System**:
- Primary font suggestion (from Google Fonts — must be free, must support German umlauts)
- Heading treatment (size scale, weight, case)
- Body text approach (size, line-height, readability emphasis)
- Color palette (primary, secondary, accent, surface, text colors — hex values)
- Color rationale (why this palette fits the concept)
- Note: Not required to use green/white — open to any professional palette

**Layout Philosophy**:
- Grid approach (max-width, columns, spacing rhythm)
- Hero concept (what does the homepage hero look like?)
- Section structure (how do content sections flow?)
- Card component style (if used — what do cards look like?)
- Navigation approach (how does the header/nav feel?)
- Mobile strategy (how does the layout adapt?)
- Footer approach

**Conversion Strategy** (same core goal, different execution):
- How does this direction communicate "membership required" early?
- Where and how does the phone CTA (07473-922202) appear?
- How does the homepage hero speak to Simone's Zweitwagen need?
- How does the pricing page build confidence?

**Inspiration Sources** (from Plan 01):
- Which student branch patterns influenced this direction?
- Which old content/owner document insights are incorporated?
