# Phase 36 Owner Instructions

- Shared comparison start page: `site/epic/index.html`
- Stable skin homepages:
  - `site/epic/a/index.html`
  - `site/epic/b/index.html`
  - `site/epic/c/index.html`

## Review Flow

1. Start on `site/epic/index.html`.
2. Choose one version first: Design A, B, or C.
3. Review that skin's homepage before switching back to the shared start page for the next option.

## What To Compare

- Which version explains membership most clearly before the phone call.
- Which version feels most trustworthy and easiest to navigate.
- Which structure and tone you would want to carry forward into publish work.

## Reminder

No winner is preselected on the comparison page. The point is to compare A, B, and C from one shared entry point without changing branches or hunting for alternate directories.
