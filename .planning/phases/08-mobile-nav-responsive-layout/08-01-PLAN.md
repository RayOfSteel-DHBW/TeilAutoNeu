    **1. Rewrite header.html for slide-down nav with peer-aria-expanded pattern:**

    Replace the current header.html with a structure that uses Tailwind's `peer` / `peer-aria-expanded:` variant for the slide-down animation. The key changes:

    - Add `peer` class to the `<button>` element (it already has `aria-expanded`).
    - Remove `hidden` class from `<nav>`. Instead, use `max-h-0 overflow-hidden` as the default collapsed state, and `peer-aria-expanded:max-h-64` as the expanded state.
    - Add transition: `transition-[max-height] duration-300 ease-in-out` on the nav.
    - On desktop (`md:` prefix): `md:max-h-none md:overflow-visible md:transition-none` to override mobile behavior.
    - The nav must push content below it when open (slide-down panel per user decision). This is achieved naturally by max-height expanding in normal flow.
    - Add `pb-4` to the nav when expanded for breathing room (mobile only); use `md:pb-0` for desktop reset.

    **Important:** The button and nav MUST be direct siblings inside the same parent div for the `peer` variant to work. Keep the existing structure where both are inside the flex container div.

    **2. Add aria-current="page" per nav link via Tera conditional:**

    In header.html, wrap each nav link's `aria-current` attribute in a Tera conditional:
    ```html
    <a href="preise.html" {% if current_page == "preise" %}aria-current="page"{% endif %}
       class="... aria-[current=page]:font-bold aria-[current=page]:text-brand-primary aria-[current=page]:bg-brand-muted aria-[current=page]:px-3 aria-[current=page]:py-1 aria-[current=page]:rounded-full">Preise</a>
    ```

    Do this for all 4 nav links:
    - `preise` -> preise.html
    - `fahrzeuge` -> fahrzeuge.html
    - `geschaeftskunden` -> geschaeftskunden.html
    - `ueber-uns` -> ueber-uns.html

    **Do NOT** output `aria-current=""` for non-matching pages — the attribute must be completely absent. Use `{% if current_page == "x" %}aria-current="page"{% endif %}` (outputs the whole attribute or nothing).

    The active page styling on desktop per user decision: bold text with background highlight (not just underline). The `aria-[current=page]:font-bold aria-[current=page]:bg-brand-muted aria-[current=page]:px-3 aria-[current=page]:py-1 aria-[current=page]:rounded-full` classes achieve this.

    **3. Override header block in all 9 page templates:**

    In each page template file, add a `{% block header %}` override that sets `current_page` and includes the header partial. The page name values are:
    - index.html -> `{% set current_page = "index" %}`
    - preise.html -> `{% set current_page = "preise" %}`
    - fahrzeuge.html -> `{% set current_page = "fahrzeuge" %}`
    - geschaeftskunden.html -> `{% set current_page = "geschaeftskunden" %}`
    - ueber-uns.html -> `{% set current_page = "ueber-uns" %}`
    - mitglied-werden.html -> `{% set current_page = "mitglied-werden" %}`
    - nachhaltig.html -> `{% set current_page = "nachhaltig" %}`
    - impressum.html -> `{% set current_page = "impressum" %}`
    - datenschutz.html -> `{% set current_page = "datenschutz" %}`

    Add this block before the existing `{% block head %}` in each template:
    ```html
    {% block header %}
      {% set current_page = "pagename" %}
      {% include "partials/header.html" %}
    {% endblock header %}
    ```

    Note: index, mitglied-werden, nachhaltig, impressum, datenschutz are NOT in the primary nav, so they won't get an active indicator — but they still need the variable set (it will just not match any nav link). The 4 nav pages (preise, fahrzeuge, geschaeftskunden, ueber-uns) will show the active highlight.

    **If Tera {% set %} inside {% block %} does not propagate to {% include %}:** Fall back to a JavaScript-based approach: remove the Tera conditionals from header.html, and instead add this to nav.js:
    ```javascript
    // Active page indicator
    const currentPath = window.location.pathname.split('/').pop() || 'index.html';
    document.querySelectorAll('#primary-nav a').forEach(link => {
      if (link.getAttribute('href') === currentPath) {
        link.setAttribute('aria-current', 'page');
      }
    });
    ```
    This JS fallback achieves the same result without template variable scoping issues. Test Tera first; use JS fallback if build fails.

    **4. Rewrite nav.js for aria-expanded toggle + keyboard support:**

    Replace the current nav.js with:
    ```javascript
    const toggleButton = document.querySelector('[aria-controls="primary-nav"]');
    const primaryNav = document.getElementById('primary-nav');

    if (toggleButton && primaryNav) {
      toggleButton.addEventListener('click', () => {
        const isOpen = toggleButton.getAttribute('aria-expanded') === 'true';
        const willOpen = !isOpen;
        toggleButton.setAttribute('aria-expanded', String(willOpen));
        toggleButton.setAttribute(
          'aria-label',
          willOpen ? 'Navigationsmenü schließen' : 'Navigationsmenü öffnen'
        );
      });

      document.addEventListener('keydown', (e) => {
        if (e.key === 'Escape' && toggleButton.getAttribute('aria-expanded') === 'true') {
          toggleButton.setAttribute('aria-expanded', 'false');
          toggleButton.setAttribute('aria-label', 'Navigationsmenü öffnen');
          toggleButton.focus();
        }
      });
    }
    ```

    Key changes from current nav.js:
    - REMOVE `primaryNav.classList.toggle('hidden', isOpen)` — the `hidden` class conflicts with `max-height` transition. The CSS peer-aria-expanded pattern handles visibility via max-height.
    - ADD `aria-label` update on toggle (German: "Navigationsmenü öffnen" / "Navigationsmenü schließen").
    - ADD Escape key listener that closes nav and returns focus to button.

    **5. Fix button spacing on index.html hero:**

    The "Mehr erfahren" / "Alle Details" buttons are glued together in the hero section. Add a gap between them. Find the container that holds both buttons and add `gap-3` or `gap-4` (Tailwind flex gap). Do NOT change button text (content changes are Phase 10). Only fix the spacing so they are not touching.
