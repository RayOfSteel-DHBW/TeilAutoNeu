# Plan 12-01: Full Visual Audit

## Objective

Screenshot all 8 pages at desktop (1280px) and mobile (375px) widths using Puppeteer MCP. Document every layout/rendering issue in AUDIT-LOG.md with page, location, width, and description.

## Tasks

1. **Navigate and screenshot each page at desktop (1280px)**
   - Navigate to each of the 8 pages
   - Take viewport screenshot at top
   - Scroll down and capture additional viewport sections for full coverage
   - Note any layout, rendering, or visual issues

2. **Navigate and screenshot each page at mobile (375px)**
   - Same process at mobile viewport width
   - Note responsive layout issues, overflow, touch target problems

3. **Document all issues in AUDIT-LOG.md**
   - Global issues (affecting all/most pages): navigation, footer, shared components
   - Per-page issues: unique to individual pages
   - Summary table with issue ID, page, location, width, description
