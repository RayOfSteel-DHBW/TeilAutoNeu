# Plan 07-01: Replace ASCII Digraphs with UTF-8 Umlauts

## Objective

Replace all ASCII digraph substitutions (ue→ü, ae→ä, oe→ö and uppercase variants) with proper UTF-8 umlauts across all HTML and JS source files. This fixes 3 blocker requirements (UX-06, QUAL-01, QUAL-02) and the "German language readability" E2E flow.

## Scope

- ~280 instances across 13 files
- Only correct visible text content, meta descriptions, OG descriptions, aria-labels, and JS string literals
- Do NOT change: file names, URLs, href values, CSS classes, HTML IDs, JS variable/function names

## Tasks

### Task 1: Fix umlauts in HTML source files
For each of the 9 HTML files in site/src/, replace German ASCII digraphs with proper UTF-8 umlauts in text content, meta tags, and aria-labels. Preserve file names and href attributes.

### Task 2: Fix umlauts in JS files
For each of the 4 JS files in site/public/js/, replace ASCII digraphs in string literals, comments, and aria-label values. Preserve variable names and code identifiers.

### Task 3: Check base template
Verify site/templates/base.html for any ASCII digraph substitutions in shared text (nav labels, footer text, meta tags).

### Task 4: Build verification
Run npm build to verify all files compile correctly after umlaut corrections.
