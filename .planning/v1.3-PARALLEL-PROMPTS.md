# v1.3 Parallel Execution Prompts

**Prerequisite:** Phase 26 (Epic Directions) must be complete. The directions document at `.planning/phases/26/26-EPIC-DIRECTIONS.md` must exist and contain all 3 structural signatures.

**How to use:** Run each prompt in a separate Claude Code session. Each session handles one design in isolation. They can be run simultaneously in separate terminals (each will checkout its own branch) or sequentially.

**Important:** If running simultaneously in the same repo clone, you MUST use worktrees or separate clones. If running sequentially, each session checks out its branch, does the work, commits, and the next session can start.
